# Video Training

Brunner materializes these files from its external resource cache before the
challenge is staged:

- `identifying-wbcs.mp4`: the Monkey Health Explorer white blood cell
  identification video.
- `identifying-wbcs.en-US.vtt`: the official English transcript for agents
  that cannot inspect video directly.

The project videos about clicking cells and using Zooniverse Talk are omitted
because this benchmark evaluates image localization and cell typing rather
than browser operation.
